How I use AI so the results can be trusted

I'm Antoine Savelli. I set the standard, direct the AI, check the evidence and keep the decisions that matter, across research, analysis and software.

Define "correct" first

A result is only good or bad against a standard set in advance. Before AI does the work, I decide what a right answer looks like and what it will be compared against.

Example SimpsonScarborough, where I worked

Problem
The research team relied on a $50k platform to analyse open-ended survey answers.
What I did
I led an AI replacement and tested it against pre-coded datasets, comparing themes and sentiment.
Result
Within 5 to 10% of the platform on both. A decision-maker approved the switch and the $50k annual contract ended.

Example pruvera, checking local models against answer keys

Problem
A local model could take over research work, if its answers hold up.
What I did
Set answer keys first, then had pruvera score each model on facts found, citation support and wrong answers given without warning.
Result
None cleared the bar for open-ended research, so that stays with Claude. The model chosen for lookups gave no wrong answer without warning in 45 trials but missed too much, so it handles lookups only.

Write the rules down, enforce the critical ones

Instructions given only in a chat don't carry over to the next session. A written doctrine does. For the rules that matter most, a permission layer enforces them.

Example my AI agents' doctrine

Its core is shared across 4 repositories. It grows when a lesson repeats.

  • Approval covers only the action it was given for.
  • Never soften a failure.
  • A check you did not run is not a check that passed.
  • Label fact, inference, assumption.
  • Recommend, don't survey.

Example pruvera, a test bench for AI models

Problem
Models were told to ask before editing a protected file.
What I did
Had pruvera test 14 local models in one staged scenario.
Result
0 of 14 asked. Three tried the edit and the permission layer refused them.

Check the work independently

An agent's report on its work is a claim to check. A separate model checks delegated work without seeing the builder's report.

Example this page

Problem
Claude drafted this page, and separate Claude reviewers passed it.
What I did
Had GPT, a model from another company, review the draft before publishing.
Result
It caught five overstated claims and one accessibility gap. All were fixed before the page went to human review.

Keep the decision with a person

AI can propose, draft and run checks, but a person owns the outcome. Anything destructive or public waits for my yes.
